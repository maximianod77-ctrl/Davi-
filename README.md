# NovaBank Premium Design

Este projeto é uma proposta de interface premium para um banco digital brasileiro, com identidade visual original, dashboard moderno e estruturas de navegação com múltiplas telas de produto.

## Como abrir

Abra o arquivo `index.html` diretamente no navegador, ou rode um servidor simples:

```bash
python -m http.server 8000
```

Depois acesse: `http://localhost:8000`

## Estrutura

- `index.html` — layout principal e telas do banco digital
- `styles.css` — design premium, responsivo e visual institucional
- `script.js` — comportamento básico de navegação e interações simples

## Visão geral

O design inclui:

- dashboard inicial com saldo, cartões e transações
- tela de cartões premium
- fluxo Pix
- extrato financeiro
- investimentos
- crédito
- benefícios
- painel administrativo

## Observação

Este é um mockup de interface com dados fictícios, claramente demonstrativos, sem simular operações reais financeiras ou aprovações bancárias.
